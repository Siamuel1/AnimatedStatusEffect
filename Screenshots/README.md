# Preview images

These original GIFs demonstrate the status sequences at two seconds per frame. They are labeled as illustrative and were generated from the matching files in `Examples/`.

They are not screenshots of a working Discord session. No actual Discord account, private messages, or session tokens appear here.

- `coding-demo.gif`: Python, JavaScript, and projects.
- `loading-dots-demo.gif`: three text steps.
- `focus-demo.gif`: focus and break messages.

The root README and the Examples guide embed these previews. Actual Discord timing can differ because of server cooldowns and client refresh behavior.
